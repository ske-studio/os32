## 10.5 テスト手順

### 基本ブートテスト

```bash
# ビルド
cd /mnt/c/WATCOM/src/os32
make all

# デプロイ
make deploy
make deploy-kernel

# NP21/W再起動後、OS32シェルから:
vdos /host/freedos98.d88
# → A:\> プロンプト表示を確認
# → DIR コマンド実行を確認
# → Ctrl+GRPH+DEL で脱出を確認
```

### ゲームテスト

```bash
# Ys D88
vdos /host/Ys.D88
# → タイトル画面表示確認
# → FM音源BGM再生確認
```

### 実FDDテスト

```bash
# NP21/Wに2HD FDDをマウント後:
v86boot
# → IPL読み込み確認
# → Ctrl+GRPH+DEL で脱出
```

## 10.6 デバッグツール

### V86デバッグダンプ

V86セッション終了時に自動出力:

```
[V86] Session ended: hotkey (F12)
[V86] GP count: 123456, INT count: 789, IRQ0 inject: 42
[V86] Timer: 500 ticks, Timeout at: CS=1FC0 IP=0003
[V86] Trace (last 128):
  1FC0:0003 CLI
  1FC0:0004 OUT 77,B6
  ...
```

### ディスクI/Oログ

64エントリのリングバッファ。セッション終了時にダンプ:

```
[DISK] #0: AH=56 AL=90 C=00 H=00 S=01 BX=0400 ES=1FC0 BP=0000 → OK (off=0)
[DISK] #1: AH=56 AL=90 C=00 H=00 S=02 BX=0400 ES=2000 BP=0000 → OK (off=1024)
```

### I/O統計

V86セッション中にアクセスされたI/Oポートの統計:

```
[V86 I/O] port=0041 R:1234 W:0
[V86 I/O] port=0043 R:5678 W:0
[V86 I/O] port=0188 R:0 W:9012 (passthrough)
```
