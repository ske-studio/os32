## 0. これは何のための票か

**アプリを 1 本増やすことが目的ではない。**
ROADMAP は「**API の退行検出を兼ねる**」と書いている。
`libos32gui` / 設定レジストリ / Host Services を**通しで使う受入試験**として、
v1.4 に 1 本だけ残されたもの。

**これが通れば v1.4 の API に穴が無いことの証明になる。** 逆に言えば、
**穴を見つけるのが仕事**であって、機能の豊かさを競う票ではない。

今日 (2026-09-17) の 3 段のランナーが「機械に読ませたら露見する穴」を 3 件出した。
**この票は「人が使う経路を通したら露見する穴」を拾う。** 角度が違う。

## 2. 中心 — 複数行の編集部品

**既存の `textbox` は 1 行用。** エディタには複数行が要る。ここが**この票で一番
API の穴が出る場所**なので、正面から扱う。

### 決裁 A1 — **新しい種類を末尾に追記する** (ユーザー、2026-09-17)

[API_CONTRACTS.md](API_CONTRACTS.md) は **「op 番号・イベント種別・構造体は末尾追記のみ。
以後の変更にはユーザ承認を要する」**と凍結している。

- **既存の `WK_TEXTBOX` は 1 行のまま。触らない。** 既存の利用者 (filer ほか) に影響が出ない。
- 複数行は **新しい種類を末尾に追記**する (`WK_TEXTAREA` 等)。**契約の「末尾追記のみ」に収まる。**
- 欠点は似た部品が 2 つ並び、描画と入力の処理が一部重複すること。**受け入れる** —
  凍結契約の変更を避けるほうが重い。

**重複は共通の下請けに寄せてよい**が、**`WK_TEXTBOX` の見え方と振る舞いを変えないこと。**
変わっていないことを試験で押さえる (受入 E10)。

残りの決めること:
- **どこまでを部品が持つか。** 折り返し / 縦横のスクロール / 選択範囲 / 桁と行の表示。
  **全部を部品に持たせない** — エディタ側が持つべきものを切り分ける。
- **1 画面に入らない大きさをどう扱うか。** 部品が本文を丸ごと持つのか、
  エディタが持って見える範囲だけ渡すのか。**後者でないと大きなファイルで破綻する。**

## 3. 本文の扱い — CUI 版を再利用しない (PM 判断)

CUI 版の中身 (行の管理・取り消し・検索) は **C で 3,248 行**ある。
Rust から呼ぶことは技術的には可能だが、**この票ではやらない。**

理由: **目的が API の穴を見つけることだから。** 言語をまたぐ呼び出しを挟むと、
不具合が出たときに「GUI の API が悪いのか、橋渡しが悪いのか」が分からなくなる。
**変数を増やさない。**

代わりに **GUI 版は意図して小さく作る**。行の配列と、挿入・削除・改行だけ。
取り消しも検索も**この票では要らない** (§6)。

**CUI 版はそのまま残る。** 2 つのエディタが併存するが、**役割が違う**ので問題ない。

## 4. 通しで使うもの (これが受入の本体)

| 使うもの | 何をするか | 何を確かめるか |
|---|---|---|
| **libos32gui** | 窓・複数行部品・メニュー・モーダル | §2。**穴が出るならここ** |
| **設定レジストリ** | 直前に開いた場所などを読む | `cfgro` の読み出しが実アプリで通るか |
| **Host Services** | **印刷** (`lpr` 相当) と**クリップボード** | `hostsvc` が実アプリで通るか |
| ファイル | 開く・保存する | VFS が GUI から通るか |

**3 つとも通すこと。** 1 つでも欠けると「通しの受入試験」にならない。

## 5. 受入

| ID | 反例・操作 | 期待 |
|---|---|---|
| E1 | gshell から起動して、開く → 打つ → 保存する | 保存した内容が CUI の `cat` で一致する |
| E2 | 1 画面に入らないファイルを開く | 縦にスクロールできる。**表示だけで本文が壊れない** |
| E3 | 日本語を打って保存する | 3 バイト 2 桁の扱いが崩れない ([`POLICY_DEBUG.md`](../../POLICY_DEBUG.md) §4-27)。**桁の数え方と折り返しの位置** |
| E4 | 選択してクリップボードへ、別の場所へ貼る | Host Services 経由で往復する |
| E5 | 印刷する | Host Services 経由でホストに出る |
| E6 | 保存せずに閉じようとする | **確かめてくる**。黙って捨てない |
| E7 | 書き込めない場所へ保存する | **理由が出る**。黙って成功にしない ([V4]) |
| E8 | ホスト試験 | 本文の操作 (挿入・削除・改行・折り返しの桁) を**ゲスト抜きで**確かめる。`--mutate` で否定側 |
| E9 | `make check-guest` と `make check` | 通る (回帰) |
| E10 | 既存の `WK_TEXTBOX` を使う画面 (filer ほか) | **見え方と振る舞いが変わっていない**。共通の下請けに寄せた結果 textbox が変わる変異で RED |

**E8 が肝。** 今日のランナーと同じ考え方で、**ゲストが要る部分と要らない部分を分ける。**
本文の操作はホストだけで試験でき、そこが壊れていたら GUI で触っても意味がない。

**E3 は特に落ちやすい。** 日本語は 3 バイトで 2 桁。**桁で折り返す部品**に入れると
UTF-8 の途中で切れる。過去に何度も踏んでいる。

## 6. この票でしないこと

- **取り消し (undo) / 検索 / 置換。** CUI 版にはあるが、**API の穴を見つける目的には要らない。**
  欲しくなったら別票。
- CUI 版 `apps/edit/` の変更。**そのまま残す。**
- 複数の窓で同時に開くこと。
- 構文の色分け、行番号以外の飾り。
- **8bpp バックエンド (R2) と About** — v1.4 の残り 2 件だが**別の票**。
