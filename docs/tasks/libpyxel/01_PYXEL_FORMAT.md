# 01: Pyxel `.pyxres` リソースフォーマット解析

## 概要

Pyxel 2.x 以降の `.pyxres` ファイルは **ZIPアーカイブ** であり、内部に単一の
**TOML形式テキストファイル** (`pyxel_resource.toml`) を格納している。

```text
sample.pyxres (ZIP)
  └── pyxel_resource.toml (TOML)
```

オプションとして、同一ディレクトリに **パレットファイル** (`.pyxpal`) を配置可能。

```text
sample.pyxpal (オプション、.pyxres と同じディレクトリ)
```

## フォーマットバージョン

```toml
format_version = 1
```

Pyxelは書き込み時に `format_version = 1` を使用する (後方互換性のため)。
ロード時はバージョン **4** まで受け入れ可能。
レガシーアーカイブ形式 (`pyxel_resource/version` + 個別ファイル) も自動検出・変換される。

## セクション構成

`format_version` と4つのセクション配列 (`images`, `tilemaps`, `sounds`, `musics`)
はすべて **必須**。Pyxelは常に全エントリ (3イメージ、8タイルマップ、64サウンド、
8ミュージック) を書き出すが、ロード時はより少ないエントリ数でも受け入れる。

### 1. イメージバンク (`[[images]]`) — 最大3バンク

各バンクは 256×256 ピクセルのインデックスカラー画像。
各ピクセルは `u8` のカラーインデックス (デフォルトパレットでは 0–15、
拡張パレット使用時は最大 0–255)。

```toml
[[images]]
width = 256
height = 256
data = [[0, 0, 10, 12, 12, 0, ...], [0, 7, 7, ...], ...]
```

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `width` | u32 | 画像の幅 (ピクセル) |
| `height` | u32 | 画像の高さ (ピクセル) |
| `data` | 配列の配列 (u8) | 2次元ピクセルデータ。外側=行、内側=カラーインデックス |

**末尾値圧縮:**
- 各行の末尾で「最後の異なる値」の繰り返し分が省略される。
- 同一の末尾行も省略される。
- ロード時、省略された値は **直前の値を繰り返して** 補完される。

例: 行 `[0, 0, 5, 5, 5, 5]` は `[0, 0, 5]` として保存される。
最後の200行がすべて `[0]` の画像は、最初の56行 + 1つの `[0]` 行のみ保存。

**データサイズ試算 (非圧縮時):**
- 1バンク = 256×256 = 65,536 ピクセル
- 16色 = 4bit/pixel → 32,768 バイト (32KB/バンク)
- 3バンク合計: 最大 96KB

### 2. タイルマップ (`[[tilemaps]]`) — 最大8マップ

各マップは 256×256 タイルの配置データ。

```toml
[[tilemaps]]
width = 256
height = 256
imgsrc = 0
data = [[10, 6, 11, 6, 12, 6, 0, 0, ...], ...]
```

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `width` | u32 | タイルマップの幅 (タイル数) |
| `height` | u32 | タイルマップの高さ (タイル数) |
| `imgsrc` | u32 | 参照するイメージバンク番号 (0-2) |
| `data` | 配列の配列 (u16) | インターリーブ形式のタイルデータ |

**フォーマット詳細:**
- タイルサイズは **8×8 ピクセル** 固定。
- 各タイルは座標ペア `(tile_x, tile_y)` (`u16`, `u16`) でイメージバンク内の位置を指す。
- TOML内では **インターリーブ形式**: `[tx0, ty0, tx1, ty1, ...]`
  (各行は `width × 2` 要素)。
- 例: タイル列 (10,6), (11,6), (12,6) は `[10, 6, 11, 6, 12, 6]` となる。
- 1マップのタイル数: 最大 256×256 = 65,536 タイル。
- イメージと同じ末尾値圧縮が適用される。

> **注意**: v2.8.8 でタイル座標の型が u8 → **u16** に変更された。

### 3. サウンド (`[[sounds]]`) — 最大64個

```toml
[[sounds]]
notes = [28, 28, 24, 19, -1, -1]
tones = [2]
volumes = [6]
effects = [2, 3, 3, 0]
speed = 25
```

すべてのフィールドは必須。空のサウンドは空配列で表現する (例: `notes = []`)。

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `notes` | 配列 (i8) | ノート値。`-1` = 休符。0 (C0) 〜 59 (B4) |
| `tones` | 配列 (u8) | 波形種別 (下表参照) |
| `volumes` | 配列 (u8) | 音量 0 (無音) 〜 7 (最大) |
| `effects` | 配列 (u8) | エフェクト種別 (下表参照) |
| `speed` | u16 | 再生速度 (tick/note)。**1 tick = 1/120 秒**。デフォルト: **30** |

**波形種別 (`tones`):**

| 値 | 波形 |
|---|------|
| 0 | Triangle (三角波) |
| 1 | Square (矩形波) |
| 2 | Pulse (パルス波) |
| 3 | Noise (ノイズ) |

**エフェクト種別 (`effects`):**

| 値 | エフェクト |
|---|-----------|
| 0 | None (なし) |
| 1 | Slide (スライド) |
| 2 | Vibrato (ビブラート) |
| 3 | FadeOut (フェードアウト) |
| 4 | Half-FadeOut (半フェードアウト) |
| 5 | Quarter-FadeOut (1/4フェードアウト) |

`tones`, `volumes`, `effects` は末尾値圧縮により `notes` より短くなることがある。
ロード時は各配列の最後の値を繰り返して `notes` の長さに合わせる。

**ノートマッピング:**
ノートは `base + octave × 12` でエンコードされる。
基準: C=0, D=2, E=4, F=5, G=7, A=9, B=11。オクターブは0〜4。
例: C0=0, A4=57, B4=59。半音は隣接する整数値。

### 4. ミュージック (`[[musics]]`) — 最大8曲

```toml
[[musics]]
seqs = [[0, 1], [2, 3], [4]]
```

`seqs` フィールドは必須。空ミュージックは空配列 (`seqs = []`)。

| フィールド | 型 | 説明 |
|-----------|-----|------|
| `seqs` | 配列の配列 (u32) | チャンネルごとのサウンドシーケンス。`seqs[0]` = Ch0, `seqs[1]` = Ch1, ... 各値はサウンド番号 (0-63) |

- 最大4チャンネル (Pyxelオーディオチャンネル 0-3)。
- 各チャンネル内のサウンドは順番に再生される。
- 保存時、末尾の空チャンネルは省略される。

## パレットファイル (`.pyxpal`)

`.pyxres` と同名・同ディレクトリに配置するオプションのテキストファイル。
1行に1色、`RRGGBB` の6桁16進数形式。

```text
000000
2b335f
7e2072
19959c
...
```

| プロパティ | 値 |
|-----------|-----|
| デフォルト色数 | 16 |
| 最大色数 | 256 |
| 形式 | 1行1色、`RRGGBB` 16進数 |

`.pyxpal` が存在しない場合、上記のデフォルトパレットが使用される。

## OS32への変換方針

`.pyxres` のTOML/ZIPをOS32上でパースするのは非現実的 (メモリ・CPU負荷)。
ホスト側 (`tools/pyxres2os32.py`) でフラットバイナリに事前変換する。

> **OS32では16色固定**: Pyxelの拡張パレット (最大256色) は使用せず、
> デフォルト16色パレットのみをサポートする。
> カラーインデックスは 0–15 の範囲に限定する。

→ 詳細は [VRAM_PLANAR.md](VRAM_PLANAR.md) を参照。
