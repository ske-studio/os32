# libos32filer — GFXファイルマネージャ・ライブラリ

## 1. 概要

`libos32filer` は、OS32のファイルシステム（VFS）を視覚的にブラウズし、ファイルやディレクトリの選択、表示、操作を行うためのファイラーUI部品を提供するライブラリです。

本ライブラリは、単体のファイラーアプリケーションとしてだけでなく、他のアプリケーション（エディタ、画像ビューアなど）における「ファイルを開く/保存する」ダイアログボックスのベース部品としても再利用可能なように設計されています。

---

## 2. ディレクトリ構成とモジュール

*   `libos32filer.h`
    *   公開API宣言、ファイラー設定構造体（カラー、カラム数等）の定義。
*   `filer_core.c`
    *   ディレクトリ走査（`sys_ls`）、ファイルリストのソート、カーソル移動による選択制御、スクロール判定などのコアロジック。
*   `filer_draw.c` / `filer_draw.h`
    *   グラフィカル（GFX）画面へのファイル・フォルダ一覧表示、フォルダアイコン、スクロールバー、およびTVRAM（テキストVRAM）を用いた高速文字描画バックエンド。

---

## 3. 主要API

### 3.1 システム制御・起動
*   `int filer_init(KernelAPI *api, const FilerConfig *cfg)`
    *   ファイラーの動作環境（ディレクトリ一覧、描画カラー、レイアウト設定など）を初期化します。
*   `void filer_shutdown(void)`
    *   ファイラー終了時の後始末を行います。
*   `int filer_run(const char *start_path, char *out_selected_path, int max_len)`
    *   指定したパスからファイラーを実行し、ユーザーがファイルを確定（Enter押下）またはキャンセル（ESC押下）するまでコントロールを維持します。確定時は選択された絶対パスを `out_selected_path` に格納して返します。

### 3.2 ディレクトリナビゲーション
*   `int filer_change_directory(const char *path)`: 表示中のディレクトリを変更します。
*   `void filer_scroll_up(void)` / `void filer_scroll_down(void)`: 表示リストをスクロールさせます。

### 3.3 カスタム描画・イベント
*   `void filer_draw(void)`: 現在のファイル一覧、スクロール位置を画面にレンダリングします。
*   `int filer_handle_key(u16 key_code)`: キー入力を処理し、カーソル移動やディレクトリ遷移などを自動処理します。

---

## 4. 特徴と設計判断

*   **TVRAM/GVRAMハイブリッド描画**: ファイル一覧の描画はテキストVRAM（TVRAM）への直接書き込みによる超高速な文字表示と、グラフィックVRAM（GVRAM）によるフォルダ/ファイル種の各種アイコン描画を組み合わせて、実機（16MHz相当）でもウェイトを感じさせない高速な応答性を確保しています。
*   **非依存のVFS設計**: FAT12、ext2、ホストドライブ（HostDrvFS）など、カーネルの仮想ファイルシステム（VFS）にマウントされた任意のパスに対してシームレスに機能します。
