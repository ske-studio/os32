# libos32md — Markdownパーサー＆レンダラー

## 1. 概要

`libos32md` は、Markdown形式（`.md`）のプレーンテキストファイルを解析（パース）し、OS32のグラフィックス画面（GFX）に見栄え良くレイアウト描画（レンダリング）するためのライブラリです。

OS32システム内のマニュアルビューア、ドキュメントビューア、ゲーム内のTIPSやヘルプ画面の描画エンジンとして使用されます。

---

## 2. ディレクトリ構成とモジュール

*   `libos32md.h`
    *   公開API、ドキュメント構造（トークンリスト）、および描画スタイル（フォント色、ヘッダサイズ等）の定義。
*   `md_parse.c`
    *   Markdown文字列のトークナイザ（簡易解析器）。見出し（`#`）、箇条書き（`-`, `*`）、太字（`**`）、コードブロック（` ``` `）、水平線（`---`）などの代表的なマークダウン記述法を抽出し、抽象構文ツリー/トークンリストを生成します。
*   `md_render.c` / `md_render.h`
    *   解析されたトークンを基に、ワードラップ処理、フォントスタイル（ヘッダの拡大・着色など）、インデント幅の計算を行い、`libos32gfx` バックエンドを介して画面に実際の位置合わせ描画を行います。スクロール位置（ビューポート）の追従機能も含みます。

---

## 3. 主要API

### 3.1 システム管理
*   `int md_init(KernelAPI *api)`
    *   Markdownレンダリングエンジンを初期化します。
*   `void md_shutdown(void)`
    *   レンダリングエンジンをクローズし、内部バッファを解放します。

### 3.2 ドキュメント解析と解放
*   `MdDocument *md_parse_file(const char *file_path)`
    *   指定したMarkdownファイルをロードし、構文解析を行って `MdDocument` 構造体（トークンリストの保持体）を返します。
*   `MdDocument *md_parse_string(const char *md_text)`
    *   メモリ上のMarkdown文字列を直接解析します。
*   `void md_free_document(MdDocument *doc)`
    *   解析済みドキュメント構造体のメモリを解放します。

### 3.3 レンダリング・表示制御
*   `void md_render(const MdDocument *doc, int scroll_y)`
    *   指定したスクロール量（ピクセル単位）を適用して、ドキュメントを画面の描画エリアにレンダリングします。
*   `int md_get_total_height(const MdDocument *doc)`
    *   ドキュメント全体のレイアウト高さ（ピクセル数）を算出します。スクロール範囲（スクロールバーのサイズ）の決定に使用します。

---

## 4. 特徴と制限事項

*   **ワードラップ（改行）対応**: PC-98の半角（ANK）および全角（日本語）の文字幅を考慮した動的な改行処理を行い、ドキュメントが画面外にはみ出るのを防ぎます。
*   **サブセット実装**: メモリと実行速度の制約上、Markdown仕様全体の完全なパーサーではなく、見出し、段落、リスト、強調、コードブロック、リンク、水平線に限定した高速サブセット実装となっています。HTML埋め込みやテーブル表記などは現在未サポートです。
