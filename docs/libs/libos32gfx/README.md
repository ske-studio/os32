# libos32gfx — グラフィックス＆描画ライブラリ

## 1. 概要

`libos32gfx` は、PC-9801/9821のグラフィックVRAM（640×400ドット、16色）に対する低レベルおよび高レベルの描画機能を提供するライブラリです。

OS32のVRAMアクセスアーキテクチャに基づき、CPUによる直接描画とバックバッファを用いたダブルバッファリング描画をサポートしています。
また、速度向上のために一部のタイトな描画ループは **NASMアセンブラ** によって最適化されています。

---

## 2. ディレクトリ構成とモジュール

*   `asm/` (アセンブラ高速描画)
    *   画面クリア、メモリ高速コピー、矩形塗りつぶしなど、VRAM転送ボトルネックになりやすい処理の32bit ASMアセンブラ最適化ルーチン。
*   `draw/` (プリミティブ描画)
    *   点、直線、矩形、円、画像のブリット（透過色対応、拡大縮小、回転）などグラフィックスの基本描画ロジック。
*   `geom/` (幾何学＆計算)
    *   ポリゴン描画、クリッピング処理、3D風変形などの計算モジュール。
*   `text/` (フォント・文字列描画)
    *   ANK（半角）文字および漢字（PC-98標準KCGフォントからロード）の画面描画制御。
*   `lconsole.c` / `lconsole.h` (仮想コンソール)
    *   グラフィカルな画面上にターミナル（テキストコンソール）をシミュレート・合成する機能。

---

## 3. 主要API

### 3.1 システム制御・バッファ管理
*   `gfx_init(KernelAPI *api)`: グラフィックスシステムの初期化。テキストGDCを停止し、グラフィック画面をアクティブ化します。
*   `gfx_shutdown()`: グラフィックス画面を閉じ、テキストモードへ復帰します。
*   `gfx_clear(u8 color)`: バックバッファを特定色でクリアします。
*   `gfx_present()`: バックバッファ（描画中バッファ）の内容をPC-98の物理VRAMへ一括転送して画面に反映します（ダブルバッファ同期）。
*   `gfx_present_dirty()`: 変更があった「ダーティ矩形」領域のみを部分転送し、物理転送コストを削減します。

### 3.2 描画プリミティブ
*   `gfx_pset(int x, int y, u8 color)`: ドットの描画。
*   `gfx_line(int x0, int y0, int x1, int y1, u8 color)`: ブレゼンハムのアルゴリズムを用いた直線の描画。
*   `gfx_rect(int x, int y, int w, int h, u8 color)`: 空白矩形の描画。
*   `gfx_fill_rect(int x, int y, int w, int h, u8 color)`: 塗りつぶし矩形の描画（アセンブラ最適化）。
*   `gfx_circle(int cx, int cy, int r, u8 color)`: 円の描画。

### 3.3 画像転送（ブリット）
*   `gfx_blit(int dx, int dy, const GFX_Surface *src, int sx, int sy, int sw, int sh)`: サーフェス画像の高速転送。
*   `gfx_blit_colorkey(...)`: 透過色を指定したスプライト画像の転送。
*   `gfx_blit_rotated(...)`: 回転ブリット（回転角を指定した転送）。

### 3.4 テキスト・フォント描画
*   `gfx_puts(int x, int y, const char *str, u8 color)`: 画面上の任意座標への文字列描画。
*   `gfx_printf(int x, int y, u8 color, const char *fmt, ...)`: 書式付き文字列の描画。

---

## 4. 特徴と設計判断

*   **ハードウェアアクセラレータ不使用**: PC-98シリーズに搭載されている EGC（Enhanced Graphic Charger）や GRCG、GDCのハードウェア機能を使用せず、**CPUによるメモリ直接書き込み（Direct CPU Rendering）のみ**で実装されています。これは、様々なPC-98互換機やエミュレータ環境における互換性を最大化するための設計上の制約です。
*   **16色パレットモデル**: PC-98標準のパレット機能を利用し、0〜15のインデックスカラーで描画を行います。
